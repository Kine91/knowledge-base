Zagadnienie 1 / 5

Event loop i blocking

Node.js wykonuje callbacki JS na głównym wątku; CPU-heavy synchroniczny kod blokuje event loop. Asynchroniczne I/O nie oznacza równoległego wykonywania JavaScript.

Praktyka / decyzja projektowa

Rozdziel CPU-heavy processing do worker_threads / osobnego workera; mierz event-loop delay i ELU. Unikaj JSON.parse ogromnych payloadów na ścieżce requestu.

Pytanie senior / pułapka

Promise.all bez limitu concurrency może wyczerpać sockety, pool DB i pamięć.

Zagadnienie 2 / 5

TypeScript to nie walidacja runtime

Typy TS znikają po kompilacji. Dane z HTTP, SQS, SAP i DB parsuj na granicy za pomocą schematów (np. Zod) i mapuj na model domenowy.

Praktyka / decyzja projektowa

type CreateOrder = z.infer<typeof schema>; const dto = schema.parse(req.body); później domenowa walidacja reguł biznesowych.

Pytanie senior / pułapka

unknown + narrowing jest bezpieczniejsze od any; nie używaj «as» do ukrywania błędów kontraktu.

Zagadnienie 3 / 5

Abort, timeout i graceful shutdown

Przekazuj AbortSignal do fetch i operacji wspierających anulowanie. Zamykając proces, zakończ przyjmowanie ruchu, dokończ in-flight, zwolnij pool i przestań pobierać wiadomości.

Praktyka / decyzja projektowa

SIGTERM → readiness false → stop HTTP intake → drain jobs (deadline) → close DB. Przetestuj rolling deployment.

Pytanie senior / pułapka

Timeout HTTP nie zatrzymuje automatycznie skutków ubocznych uruchomionych w tle.

Zagadnienie 4 / 5

Architektura kodu

Zależności kieruj ku domenie: controller → use case → port → adapter. DTO API, encja persistence i model domenowy to nie zawsze ten sam obiekt.

Praktyka / decyzja projektowa

UseCase przyjmuje repo interface, clock i event publisher; test jednostkowy podmienia zależności bez Postgresa.

Pytanie senior / pułapka

Nie wprowadzaj abstrakcji i wzorców bez realnej potrzeby; «clean» nie znaczy maksymalnie wiele plików.

Zagadnienie 5 / 5

Typowe pytania

Jak działa microtask queue? Jak debugować memory leak? Jak dobierasz concurrency? Jak zapewniasz correctness przy retry?

Praktyka / decyzja projektowa

Ćwiczenie: endpoint POST /orders z Idempotency-Key, walidacją, transakcją i obsługą konfliktów.

Pytanie senior / pułapka

Wytłumacz różnicę między process.nextTick, Promise microtasks a timerami bez opierania projektu na detalach kolejności.
